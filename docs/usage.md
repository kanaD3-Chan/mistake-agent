# 使用说明

## 1. 前置配置

数据根目录：`~/Documents/.mistake-agent/`（Windows：`%USERPROFILE%\Documents\.mistake-agent\`）。首次运行前创建 `settings.json`：

```json
{
  "log_level": "info",
  "english_mode": false,
  "nickname": "",
  "main_model": {
    "api_url": "https://api.deepseek.com",
    "api_key": "你的 DeepSeek key",
    "model": "deepseek-flash",
    "transport": "responses"
  }
}
```

单份 DeepSeek 配置即承担对话、调度、判分、摘要与图片理解（图片经 Responses API 的 `input_image` 直传）。`vision_model` 字段仅为兼容旧配置保留，运行时不再读取。

**或者，不填 `api_key` 而登录平台服务**（2026-09-30 起，ADR-0048）：首次启动会出现登录/注册页，登录成功后模型调用走平台中转，**不需要自备 Key**（额度来自平台套餐）。不登录也可以——页面上有「先跳过，用本地模式」，点过之后不再出现（选择记在本机 `localStorage`），行为与以前完全一致。

`account` 段由应用自己维护，一般不需要手改：

```json
{ "account": { "server_url": "http://8.131.146.250:8080", "token": "", "email": "", "role": "", "sync_enabled": false } }
```

`token` 为空 = 本地模式（用上面的自备 Key），非空 = 平台模式。`email` / `role` / `sync_enabled` 由服务端回执写入，客户端只读展示。

## 2. 启动

```bash
# 改过前端后先构建（否则用旧的嵌入资源）
cd web && npm install && npm run build && cd ..

# 开发运行
cargo run --bin mistake-agent
```

## 3. 界面操作

- **聊天**：底部输入框发消息，Enter 或「发送」。
- **显式调用工具**：在输入框输入工具名（如 `practice::generate`），前端弹出工具候选框，**按 Tab 确认**后输入框显示工具徽章与淡色 `<可选参数>` 占位；输入参数（可省略）后 Enter 发送，Agent 会**强制调用该工具**并基于结果在聊天中讲解（不绕过 LLM）。工具清单、名称、图标、用法示例全部来自后端。
- **批改作业**：点「作业」选择图片/PDF → 附件随消息发送（图片直入模型上下文，PDF 自动抽取正文）→ 模型读图判分后调 `grading::upload` 归档错题。
- **附件展示**：上传的图片会直接渲染在聊天气泡里，PDF 显示图标与文件名；点击可查看大图或完整 PDF。附件持久保存在数据根目录 `uploads/`，不随系统临时文件清理而丢失。
- **连续历史**：同一会话内聊天记录完整保留（旧消息自动携带，不回退）；**模型不会自作主张换话题**，开新会话由用户决定、旧会话自动归档，左侧栏常驻的会话列表里仍可查看并切回全部记录。
- **错题本**：左侧栏底部导航「错题本」直接查看错题列表（学科/知识点过滤、题目/作答/参考答案/错因）；也可在聊天里问"错题本里有什么"。
- **会话列表**：左侧栏常驻的列表（按最近活动倒序，名字由模型按首条消息生成、可重命名/删除），点侧栏顶部的「新对话」开新会话（同时回到聊天页）、点任意会话切回；品牌行右端的箭头可把侧栏收成图标条（只留导航图标，选择会被记住），再点一次展开。聊天中可对 assistant 消息编辑/重新生成，用 < > 切换消息树分支（只在当前会话内）。
- **设置**：左侧栏底部导航「设置」配置昵称、DeepSeek 模型的 URL、Key、模型 ID、接入方式与日志级别；昵称显示在左下角，留空则为「同学」；「英语练习模式」开启后，模型对话、判分、出题与复盘统一使用英文，界面文字保持中文；Key 只显示"已设置"状态，留空表示保留原 Key。设置页还有「教学规则（AGENTS.md）」卡片：展示规则是否已加载（缺失/损坏/超限会回退默认规则），可一键用系统默认程序打开规则文件编辑，保存后即时生效；英文模式下中文规则照常加载，由模型理解后用英文输出。
- **登录 / 注册（可选）**：首次启动会盖一层登录页，可注册新账号或登录已有账号；服务端地址在页面上可改（改完需重新登录）。**登录是纯可选的**——点「先跳过，用本地模式」即与以前完全一样，不登录也能用全部功能（只是模型走你自己填的 Key）。跳过之后想登录，点左下角卡片里的「登录平台服务」即可把页面叫回来。
- **左下角账户区**：头像（描边颜色即内核状态：绿=就绪、琥珀=忙碌、灰=未就绪）+ 昵称，点开弹出小卡片。**未登录**时是「登录平台服务」「下载手机端」「帮助与反馈」；**已登录**时卡片顶部显示邮箱与角色，条目变成「下载手机端」「帮助与反馈」「退出登录」。后两项仍**尚未支持**（没有移动端、没有反馈通道），点了会在卡片里如实说明，不会静默无反应。
- **退出登录**：点卡片里的「退出登录」即退出平台账号，模型链路立刻切回你自备的 Key（不需要重启）。**本地数据一个字节都不动**——错题本、会话记录、记忆全都留着（账号与本地数据不分家，同步是后续功能）。服务端地址会保留，下次登录不用重填。断网时也能正常退出，只是服务端那条令牌到期自然失效。
- **停止**：回答/批改过程中点「停止」立即中止（回合中发送按钮禁用，先停止再发新消息）。
- **思考过程**：模型推理增量默认折叠在"思考过程"卡片里，点击展开/折叠；不展示给学生也随时可查。
- **工具进度**：批改中底部显示"grading::upload：正在识别…"等进度。
- **验算**：让 Agent 验算数学题（如"用 Python 验证 3x+5=11 的解"），Agent 调 `compute::verify`，代码在应用内 Pyodide（WASM 沙箱）执行。
- **练习/复盘/组卷/追踪**：聊天里说"生成一道全等三角形变式题 / 我的薄弱点在哪 / 批改一下这道题 / 给我周复盘 / 出 5 道薄弱点试卷 / 检查我的掌握度"，Agent 分别调 `practice::generate`、`practice::gaps`、`practice::check`、`report::weekly`、`exam::compose`、`tracking::checkin`。

## 4. 数据与产物

| 路径 | 内容 |
|---|---|
| settings.json | 模型配置与 key、平台账号登录态（`account` 段） |
| sessions/<key>.jsonl | 会话消息树（首行元数据） |
| mistakes/mistakes.json | 错题本 |
| memory/ | 记忆条目（文件持久化；中文路径编码落盘，应用层路径不变） |
| uploads/ | 作业附件持久副本 |
| data/ | 运行时教学数据（真题池等） |
| audit/audit.jsonl | 审计（10MB 轮转） |
| logs/ | 分级诊断日志（10MB 轮转） |

## 5. 常见问题

- 发送后没反应：确认左下角头像旁的状态为"就绪"（内核自检通过）；查看 `~/Documents/.mistake-agent/logs/` 诊断日志。
- 扫描版 PDF：提示不支持，请拍照成图片再上传。
- 模型报"余额不足/模型不可用"：检查对应 key 与官方模型状态。
- 登录页一直转圈或提示连接失败：多半是「平台服务地址」不通（默认地址指向生产服务端，未部署或未放行端口时就是连不上）。这不影响使用——点「先跳过，用本地模式」即可，或把地址改成自建服务端的地址。出于安全，客户端不会提示"账号不存在还是口令错误"之外的信息（邮箱是否存在也无从判断）。
- **会话中途回答突然没了、没有报错**：可能是平台登录已过期（令牌失效），此时模型调用被拒但回合内没有文案——这是**已知缺口**（计划随 S5-B 补齐提示气泡）。重启应用即可看到侧栏提示登录已失效、令牌已被清除；重新登录即可恢复。**本地数据不会因此丢失**（登出与令牌失效都不碰错题本 / 会话 / 记忆）。
- 登录后想自己填 Key：先在左下角「退出登录」，模型链路会立刻切回自备 Key。

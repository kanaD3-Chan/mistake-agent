# 页面覆盖：聊天（chat）

基于 MASTER.md（Flat Design，教育 teal #0D9488 + 课程 amber #D97706），以下为本页专属规则：

- 主操作区：消息流（用户右侧 teal 气泡、助手左侧白卡），流式光标 + 打字机增量。
- 布局：聊天区自身只占一列（`.chat-page` → `.chat-col`），会话列表常驻**应用侧栏**（侧栏顶部的「新对话」按钮与底部导航之间，详见 [sessions.md](sessions.md)）；聊天列**只渲染当前会话**，不开新话题就不换会话——换会话只由用户在列表里发起（ADR-0044）。侧栏顶部那个「新对话」按钮占的是原「聊天」导航位，也是**唯一**的开新会话入口。
- 思考过程默认折叠（`details`），图标 `mdi:brain`。
- 工具执行状态以底部胶囊呈现，图标来自内核事件（Iconify `mdi:*`）。
- 分支与编辑：用户气泡在回读会话后显示编辑按钮；同一父节点存在多个子消息时显示分支按钮（点击循环切换）。分支切换**只在当前会话内**，不承担会话边界语义。
- 切换/新建会话时先重置流式状态（气泡、增量下标、待发送 id、编辑态、工具状态），避免上一会话的半截气泡串到新会话。
- 会话标题更新（`session_title_updated`）只刷新左侧列表，不打断正在阅读的消息流。
- 动画：消息入场 280ms 上浮淡入；工具胶囊 200ms 淡入淡出；全部尊重 `prefers-reduced-motion`。
- 触屏（hover:none）：气泡操作按钮常显；桌面端 hover 显示、focus-within 常显。
- 输入区：44px 触控目标，文件选择（mdi:upload）、发送（mdi:send，amber CTA）、停止（mdi:stop-circle）。
